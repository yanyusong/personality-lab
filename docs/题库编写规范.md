# 《自我认知 360》题库编写规范

> 给内容生成者（人或 AI）看。目标是让 13 个维度的题目**风格统一、计分正确、能直接编译**。

## 1. 目录与文件

每个维度两个文件：

```
core/bank/<dimId>.ts    → 导出 <PREFIX>_ITEMS: Item[]（20 题）
core/text/<dimId>.ts    → 导出 <PREFIX>_TEXT: Record<string, SubText>（子维度文案）
```

`<dimId>` 用 dims.ts 里的 id（camelCase）。`<PREFIX>` 用全大写常量名，建议取维度缩写。

## 2. core/bank/<dimId>.ts 格式

```ts
import type { Item } from "../adaptive";

// <维度名>维度题库：10 道筛查 + 10 道追问，覆盖 <sub1>/<sub2>/<sub3>/<sub4>
export const XXX_ITEMS: Item[] = [
  {
    id: "xx01", dim: "<dimId>", subDim: "<subDimId>", kind: "sjt", discrimination: 0.9, screener: true,
    text: "一句具体的场景描述。",
    options: [
      { id: "A", label: "选项文字", scores: { sub1: 1 } },
      { id: "B", label: "选项文字", scores: { sub1: -1 } },
      { id: "C", label: "选项文字", scores: { sub2: 1 } },
      { id: "D", label: "选项文字", scores: { sub2: -1, sub1: 1 } },
    ],
  },
  // ... 共 20 题
];
```

### Item 字段约束（严格）

| 字段 | 要求 |
|---|---|
| `id` | `<前缀>01` ~ `<前缀>20`，不重复 |
| `dim` | 必须等于文件名对应的 dimId |
| `subDim` | 该题的**主载荷**子维度，用于自适应选题；必须是该维度 subDims 里的 id |
| `kind` | 固定写 `"sjt"` |
| `discrimination` | 0.70 ~ 0.90，题越能区分人越高 |
| `screener` | 前 10 题写 `true`，后 10 题写 `false` |
| `text` | 一句话场景，第二人称，**不要**用「你是否…」这种问卷腔 |
| `options` | 固定 4 个，id 为 A/B/C/D |
| `options[].scores` | 1-2 个子维度，值只能写 `1` 或 `-1` |

### 数量要求

- **20 题**：10 道筛查（screener: true）+ 10 道追问（screener: false）。
- 每个子维度：**至少 2 道筛查题 + 至少 2 道追问**。4 个子维度 = 至少 8+8，剩下 4 题分配给最需要区分的子维度。
- 4 个选项要代表**不同的行为倾向**，不能有一个选项明显是「正确答案」。三个是合理的不同做法，一个是偷懒/回避的做法即可。

### 计分约定

- `scores: { subDimId: 1 }` 表示选它 → 该子维度 **+1**（该特质高）。
- `scores: { subDimId: -1 }` 表示选它 → 该子维度 **-1**（该特质低）。
- 一个选项可以同时给两个子维度打分，但**不要超过两个**，否则分数会被稀释。
- **负极性子维度**（polarity: negative，如自我苛责、内耗、拖延、愧疚感、被评价敏感度）：`1` 表示这个**问题更重**，`-1` 表示这个问题更轻。文案要按这个方向写，不要写成「高 = 好」。

## 3. core/text/<dimId>.ts 格式

```ts
import type { SubText } from "../interpret";

export const XXX_TEXT: Record<string, SubText> = {
  sub1: {
    name: "子维度名（与 dims.ts 完全一致）",
    high: "高分端（60 分以上）的行为描述，一句话，具体，不写形容词堆砌。",
    low: "低分端（40 分以下）的行为描述，一句话。",
    mid: "中间段（40-60）的描述，一句话，承认两种倾向都有。",
  },
  // ... 每个子维度一条
};
```

### 文案要求

- 每句 **不超过 40 个汉字**。
- 写**行为**，不写评价（不写「你很优秀」「你不够好」）。
- 不用心理学术语（不写「依恋焦虑」「执行功能」）。
- 高/低两端要**都是客观描述**，不褒不贬。例如「倾听」高分端写「会先听完再回应」，低分端写「对方说话时容易在心里准备反驳」——低分不是骂人。
- **负极性**子维度的高分端要写问题本身（如「犯错后会反复回想，对自己说重话」），低分端写健康状态（如「犯错后能就事论事，不太攻击自己」）。

## 4. 文风参考（已上线的 4 个维度）

题目示例（工作维度）：

> 一个没人催、也没人检查进度的任务交到你手上。
> A 自己定节点，按计划推进
> B 等有人问起才动
> C 先做别的更急的
> D 找人一起做，互相监督

特点：**场景 + 四个真实会发生的反应**，没有「请选择最符合你的」这种提示语，没有对错。

## 5. 完成后自检

1. `npx tsc -p tsconfig.json --noEmit` 能过（类型对）。
2. 20 题 id 连续、无重复。
3. 每个 subDim 都至少被 2 道筛查题和 2 道追问覆盖。
4. 所有 `scores` 的 key 都在 dims.ts 该维度的 subDims 里。
